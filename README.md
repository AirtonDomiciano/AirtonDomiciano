# Hi, I'm Airton Domiciano 👋

Full-Stack Developer focused on building reliable ERP, financial and operational systems with **Angular, NestJS, TypeScript and SQL Server**.

I work across the full delivery cycle: understanding business rules, designing maintainable solutions, reviewing code, validating releases and continuously improving legacy systems. I’m especially interested in complex financial and fiscal workflows, system architecture, developer experience and practical AI applications.

## What I do

- Build and evolve large-scale **ERP modules** for finance, tax and inventory operations.
- Design modern Angular interfaces and robust NestJS APIs using **GraphQL, TypeORM and SQL Server**.
- Turn complex business rules into clear, testable and maintainable code.
- Review pull requests and help keep deliveries safe through testing, pipelines and release validation.
- Explore AI agents, retrieval and persistent technical knowledge to improve developer workflows.
